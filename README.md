# Каталог учебных аудиторий

Реализована программа для работы с каталогом учебных аудиторий.
Можно добавлять, искать и получать информацию об учебных аудиториях, удалять учебные аудитории, а также сохранять каталог в JSON-файл. Реализована возможность загрузки каталога в json-файл.

## Возможности
- Создание объектов учебных аудиторий с проверкой данных;
- Добавление и удаление аудиторий;
- Поиск аудиторий по категории и имени;
- Проверка уникальности объектов;
- Перебор объектов в порядке их добавления;
- Сохранение каталога в JSON-файл;
- Загрузка каталога из JSON-файла;
- Проверка корректности загружаемых данных, путем обработки ошибок.
